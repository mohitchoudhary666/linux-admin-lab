# Linux security fundamentals

- Apply distribution security updates through the documented package manager and an approved maintenance process.
- Use individual accounts and least privilege; audit membership in administrative groups.
- Prefer SSH keys or an approved identity system, disable password-based remote access only after confirming an alternate access path, and restrict management access to trusted networks.
- Keep services and listening ports to the minimum required; verify intent before changing firewall policy.
- Protect backups and logs because they can contain personal or operational data.
- Avoid copying secrets into shell history, source control, issue comments, or screenshots.
- Review vendor advisories and your organization's baseline; this learning guide is not a substitute for a production security standard.
